# ML Modeling Skill

스마트 공장 제품 품질(0, 1, 2) 분류 모델을 학습시키기 위한 가이드입니다.

## 지침
1. **결측치 처리**: 단순히 평균으로 채우지 말고, 트리 모델 기반 자체 결측치 처리 기능을 활용하거나 비즈니스 로직(공정 미진입 등)을 반영한 값(-1 등)으로 채우세요.
2. **클래스 불균형**: 타겟 클래스(`Y_Class`)의 분포를 확인하고, `class_weight='balanced'`를 적용하거나 SMOTE 처리를 고려하세요.
3. **베이스라인**: 초기 모델로 Random Forest 혹은 LightGBM을 사용하여 빠르게 성능(Macro F1)을 측정하세요.
4. **최적화**: Optuna를 사용하여 베이지안 최적화 기반으로 하이퍼파라미터를 튜닝하세요.
5. **모델 저장**: 튜닝이 완료된 모델은 `joblib`이나 `pickle`을 사용해 `models/` 폴더에 저장하세요.

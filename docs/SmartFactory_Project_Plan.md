# 스마트 공장 제품 품질 상태 분류 AI 프로젝트 구상안

## 📌 프로젝트 개요
* **프로젝트명 (가제)**: 스마트 공장 제조 공정 데이터를 활용한 제품 품질 다중 분류 및 원인 분석 시스템
* **기반 데이터**: LG Aimers 해커톤 (DACON 236055)
* **목표**: 실제 스마트 공장 데이터(공정 라인, 센서 수치 등)를 분석하여 제품의 최종 품질 상태(기준 미달/적합/기준 초과)를 예측하고, 불량 원인을 도출하는 AI 파이프라인 및 모니터링 대시보드 구축

---

## 1. 프로젝트 배경 및 문제 정의
* **배경**: 제조업에서 제품 품질은 기업 이익과 직결되나, 수많은 공정과 센서 변수로 인해 불량 원인을 직관적으로 파악하기 어려움.
* **해결 과제**: 
  * 공정 진행 중 발생하는 센서 데이터를 바탕으로 품질 불량(Under/Over-yield)을 조기 예측.
  * 불량 발생 시, 어떤 공정/센서가 가장 큰 영향을 미쳤는지(Feature Importance) 역추적하여 공정 최적화 인사이트 제공.

---

## 2. 핵심 과제 및 데이터 전처리 전략
실제 현장 데이터의 특성(많은 결측치, 극심한 클래스 불균형)을 해결하는 것이 주요 어필 포인트입니다.

* **결측치(Missing Value) 처리 전략**
  * 공정(Line)에 따라 측정되지 않는 센서 값(NaN) 처리.
  * 결측치 자체를 정보로 활용할 수 있도록 -1 등 특정 상수값으로 대체하거나, 트리 모델의 고유 결측치 처리 기능 적극 활용.
* **파생 변수 생성 (Feature Engineering)**
  * `TIMESTAMP` 변수를 분해하여 시간대, 요일, 교대조 형태의 파생 변수 생성.
  * 특정 라인별 센서 통계값(평균, 분산, 최대/최소값) 등 집계 변수 추가.
* **클래스 불균형(Class Imbalance) 해소**
  * 정상(1) 데이터 대비 현저히 적은 불량(0, 2) 데이터 처리.
  * SMOTE 기법, 모델의 Class Weight 조정, Focal Loss 적용 등을 통한 소수 클래스 예측력 강화.

---

## 3. 모델링 및 하이퍼파라미터 튜닝
* **알고리즘 선정**: 다수결 결측치 처리에 강하고 비선형 관계 학습이 뛰어난 트리 기반 앙상블 모델(Random Forest, LightGBM, XGBoost, CatBoost) 활용.
* **하이퍼파라미터 튜닝**: `Optuna` 라이브러리를 활용한 Bayesian Optimization으로 모델 성능 최적화.
* **앙상블(Ensemble) 전략**: Soft Voting 혹은 Stacking Ensemble을 구성하여 단일 모델의 과적합을 방지하고 일반화 성능(Macro F1 Score) 극대화.

---

## 4. 모델 해석 및 시각화 (Explainable AI - XAI)
* 단순히 "성능이 좋은 모델"을 넘어, 모델이 왜 그런 예측을 했는지 설명.
* **SHAP (SHapley Additive exPlanations)** 분석을 적용하여 각 센서 변수가 품질(0, 1, 2) 판정에 미친 기여도를 시각화.
* **인사이트 도출**: "특정 라인의 A 센서 온도가 X 이상일 때 불량 발생 확률이 N% 증가한다"와 같은 실무적인 인사이트 도출.

---

## 5. 포트폴리오 차별화: 웹 대시보드 구축 (MLOps/Serving) 🌟
주피터 노트북 환경을 벗어나, 현장 실무자나 면접관이 직접 조작해 볼 수 있는 인터랙티브 대시보드를 구축합니다. (`Streamlit` 권장)

* **실시간 모니터링 대시보드**: 제품 생산 현황 및 예측된 품질 분포 시각화.
* **개별 제품 상세 분석**: 특정 제품 ID 검색 시, 해당 제품의 불량 예측 사유를 SHAP 플롯으로 즉각 설명해주는 UI 제공.
* **What-if 시뮬레이터**: 사용자가 가상의 센서 값을 조정해보고, 예측 품질이 어떻게 변하는지 실시간으로 확인 가능하도록 구현.
